## Required release procedure, per asset

1. Independently inspect original file and any parent/derivative revision; verify that the named creator is the actual photographer/rightsholder, not merely the uploader; record license wording and any incompatible restrictions or trademark/personality concerns. Missing or conflicting authorship blocks publication.
2. Inspect the **actual image** for historical subject, uniform/team/year context. All alt/caption suggestions above are deliberately provisional. Replace them with visually verified bilingual text and separate precise English/Ukrainian captions.
3. Acquire the intended original only through the existing safe Commons/private-ingestion path; do not bypass 429 throttling. Verify observed SHA-1 and complete locally computed SHA-256, MIME, dimensions, file integrity, credit and exact derivative license obligations.
4. An independent human reviewer must approve the **exact** `mediaFingerprint`, source context, EN/UK text and intended website usage; record a real review, never synthesize sign-off.
5. Deliver reviewed bytes and the complete matching `apps/web/src/components/media/publication.json` entry in one PR; verify EN/UK hero/gallery and source attribution, 320px/200% text, keyboard, no hotlinks, withdrawal behavior, complete CI.
