## Findings requiring explicit QA

1. **File descriptions are not necessarily coherent historical evidence.** The Verstappen file's 2016 April capture vs post-May Spanish victory description is a concrete mismatch. Treat its subject as **2016 Toro Rosso context pending verification**, not “Spanish GP victory”.
2. **Photo date and depicted-event year differ.** The Schumacher 1997 file has a 2006 metadata date; the Lauda 1976 file has a 2017 date. This does not prove the description false, but demands a derivative/source-chain check.
3. **FlickrReview is evidence of a license tag at review time, not proof of subject identity or unlimited rights.**
4. **Cross-era photo context must be visible.** A 2024 Alonso portrait should not be used as a 2005 Renault race image.
5. Keep all candidates in the **research lane**. No synthetic reviewer, no fabricated SHA-256, no automatic import into `apps/web/src/components/media/publication.json`.
