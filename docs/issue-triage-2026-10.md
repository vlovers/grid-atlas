## Triage workflow

1. For each candidate, inspect the issue checklist, merged PR diffs, and current code; do not close on title similarity.
2. Where a checklist is partly fulfilled, comment with exact remaining criteria and retain the issue.
3. Close only after a reviewer confirms all criteria, citing the implementing PR(s).
4. Preserve editorial approval and production deployment as independent gates.
