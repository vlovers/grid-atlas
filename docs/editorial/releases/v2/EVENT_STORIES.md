# Event-specific bilingual narratives — 11 subjects, 22 scenes

This packet replaces generic “a race result is a starting point” copy with event-specific, source-linked EN/UK manuscripts for three constructors and eight circuits. Each subject has a race scene and a classification scene, tied to its corresponding official-result cross-check. Seven subjects have source-recorded runner-up and third-place details; four use only the winner/lap evidence of season index pages, and explicitly omit unsupported podium claims.

The content is intentionally narrow: no inferred overtakes, weather, emotional states, title implications, car specifications, first-win superlatives or track layout diagrams. The archive venue ID is not a historical layout ID. The manuscripts are editorial drafts, **not live website content**. Independent source and language review remains mandatory. The CI audit checks locale completeness, evidence links and unpublished state, but cannot substitute for historical fact-checking.
