# Eleven exact race identities from the pinned F1DB archive

This research packet was transcribed from the **actual GitHub Actions artifact** `editorial-event-candidates-unapproved` (artifact 12412077337, workflow run 39747904966), generated against pinned `f1db/v2026.17.0`. The year-scoped report enumerates all race candidates, so a race was selected only after comparing the existing lead's Grand Prix, year and named winner against the archive's race title, circuit external ID and winning constructor/driver external IDs.

The resulting JSON contains the **exact archive race ID, date, round, canonical race title, circuit external ID and winner identities for all eleven leads**. The three constructor leads have a matching winner constructor ID: Williams (1979 British GP), Mercedes (1954 French GP) and Red Bull (2009 Chinese GP). The remaining eight circuit leads have an explicit race venue ID. This is a **data identity match, not independent historical verification**: F1DB can still contain errors, and the original official F1 index leads need event-specific review.

Special identity caveats: the source circuit IDs for the Circuit of the Americas and Albert Park are `austin` and `melbourne`; these are not literal matches to the editorial slugs. The Nürburgring editorial slug contains transliteration artifacts, while the source circuit ID is `nurburgring`. **No layout identity has been established**, and no track geometry or historic layout may be inferred from the venue IDs. The 1954 French GP winning constructor is Mercedes, but a 1954 Belgian GP Fangio win in the same season is attributed to Maserati in the archive: a driver/year-only join would have been incorrect.

Run `python3 scripts/audit-editorial-archive-matches.py` and `python3 -m unittest discover -s tests -p 'test_editorial_archive_matches.py'`. Both tests are structural. Every item remains unapproved, unpublished and pending an independent source review before it can be incorporated as a historical assertion on the public site.
