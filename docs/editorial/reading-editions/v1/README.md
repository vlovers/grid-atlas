## Editorial boundaries

- Statements and source locators are transcribed from existing locale-specific research dossiers, without expanding their factual scope. Links point to existing source pages, not independently reverified web snapshots.
- Original dossier JSON and claim IDs remain the canonical review inputs. These Markdown reading editions are for narrative editing, accessibility and bilingual copy review only; **do not import them into the publication database**.
- Attribution and evidence do not establish independent historical correctness. Claims about disputed events, titles, official standings and driver motives require source-specific review.
- User authorization to proceed with editorial work does not constitute an independent human review or authorize falsifying `actor: human`, revision digests or approval sidecars.
- Existing [exact-revision publication process](../../APPROVED_RELEASE_PIPELINE.md) remains mandatory for publication. No photographic rights were approved.
