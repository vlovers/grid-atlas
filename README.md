# Grid Atlas

An open-source, interactive atlas of Formula One championship history, beginning in 1950.

> Working project name. Brand and visual direction are intentionally undecided.

## Status

Early foundation phase. Historical facts and licensing will be verified against upstream sources before production ingestion.

## Principles

- Source-attributed history; clearly distinguish facts, interpretation and uncertain relationships.
- Keep teams, constructors, entrants and ownership lineages distinct.
- Reproducible, versioned imports; do not overwrite editorial corrections.
- Small, reviewed changes with automated checks.
- No use of unlicensed Formula One logos, photographs or copyrighted media.

See upcoming architecture and foundation pull requests for technical setup.
